04 / METHODOLOGY

Project details

Analysis workflow

1. Capture authorized traffic using Wireshark.

2. Clear display filters before full-capture analysis.

3. Open Statistics → Protocol Hierarchy.

4. Record results and investigate suspicious patterns using packet details.

Data integrity

Results were manually entered from a Wireshark screenshot. Verify them against the original capture before submitting.

This is a static dashboard, not a live packet sensor or a complete PCAPNG parser.

Only capture traffic you own or have permission to analyze.
